# ロト6 被りにくい番号メーカー

スマホのブラウザで使える、ロト6の番号選びツールです。

**「他人と被りにくい組み合わせを買えば、当たったときに山分けになりにくく、取り分が増える」**という考え方（特にキャリーオーバー時に有効）に基づいて番号を生成します。

> ⚠️ どの組み合わせも**当せん確率そのものは同じ**です。このツールが変えるのは「当たったときの取り分の期待値」だけです。

## 機能

- **被りにくい番号の生成** — 日本人の番号選択の傾向（誕生日の1〜31、ラッキー7などが人気／4・9・42などの忌み数は不人気）を点数化し、人気の低い組み合わせを選出
- **マークシート単位の表示** — 1枚＝A〜Eの5口 × 最大10枚（50口）。全口の重複なしを保証
- **口ごと・全部まとめてのコピー** — 売り場やネット購入時に転記しやすい形式
- **数字ごとの出現回数ランキング** — 第1回（2000年10月）からの全当せんデータを集計。**毎週月・木の抽選後に自動更新**

## 仕組み

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（1ファイル完結・ライブラリ依存なし） |
| `freq.json` | 番号ごとの出現回数データ。アプリが起動時に読み込む |
| `update_freq.py` | 全当せんデータを取得して `freq.json` を再集計するスクリプト |
| `.github/workflows/update-freq.yml` | GitHub Actions の設定。毎週月・木 23:00 JST（＋翌朝の保険実行）に自動集計・コミット |

`freq.json` が読み込めない環境でも、`index.html` に内蔵された予備データで動作します。

## 公開方法

GitHub Pages（Settings → Pages → Branch: main）で公開するか、Netlify にリポジトリを接続してください（ビルドコマンドなし・公開ディレクトリ `.`）。

## データ出典

当せんデータは [ロト6データ](https://loto6.thekyo.jp/) 提供のCSVを利用しています。

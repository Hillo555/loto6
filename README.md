# ロト6 番号メーカー

スマホのブラウザで使える、ロト6の番号選びツールです。**作戦**と**集計期間**を選んで番号を生成します。

| 作戦 | 内容 |
|---|---|
| **出やすい** | 出現回数の多い数字を中心に組む |
| **両取り**（おすすめ） | よく出ていて、なおかつ他の人が選びにくい数字を優先 |
| **被りにくい** | 他の人が選ばない数字で組み、当たったときの取り分を最大化 |

| 集計期間 | 内容 |
|---|---|
| **全期間** | 第1回（2000年10月）からの全記録で数える |
| **直近10回** | 最新10回分だけで数える（最近の流れ重視） |

集計期間は「出やすい」「両取り」に効きます。「被りにくい」は出現回数を使わないため無効化されます。

> ⚠️ **どの組み合わせも当せん確率そのものは同じです。**
> 出現回数の差は偶然のゆらぎであり、「出やすい数字」でも「しばらく出ていない数字」でも当たりやすくはなりません。第301回以降の全1,824回でのバックテストでは、その時点で出現回数が**少なかった**10個が次に出た数は平均1.42個、**多かった**10個は1.36個（無関係なら1.40個）で、どちらの偏りも統計的に確認できませんでした。直近10回で見た場合も同様です（よく出た10個で平均1.40個＝理論値どおり）。
> 一方「被りにくい」組み方には、当せん時に山分けになりにくい（＝取り分が増える）という実際の効果があります。

## 機能

- **3つの作戦 × 2つの集計期間の切り替え** — 押すとその場で番号を作り直し
- **マークシート単位の表示** — 1枚＝A〜Eの5口 × 最大10枚（50口）。全口の重複なしを保証
- **枚ごと・全部まとめてのコピー** — 売り場やネット購入時に転記しやすい形式
- **数字ごとの出現回数ランキング** — 選んだ集計期間に連動。**毎週月・木の抽選後に自動更新**され、番号生成にも最新の集計が使われます

## 仕組み

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（1ファイル完結・ライブラリ依存なし） |
| `freq.json` | 番号ごとの出現回数データ。アプリが起動時に読み込む |
| `update_freq.py` | 全当せんデータを取得して `freq.json` を再集計するスクリプト |
| `.github/workflows/update-freq.yml` | GitHub Actions の設定。毎週月・木 23:00 JST（＋翌朝の保険実行）に自動集計・コミット |

`freq.json` が読み込めない環境でも、`index.html` に内蔵された予備データで動作します。

## 公開方法

GitHub Pages（Settings → Pages → Branch: main）で公開するか、Netlify にリポジトリを接続してください（ビルドコマンドなし・公開ディレクトリ `.`）。

## データ出典

当せんデータは [ロト6データ](https://loto6.thekyo.jp/) 提供のCSVを利用しています。
